Problem Statement
>People often struggle to keep track of their daily expenses, which leads to confusion about spending habits and difficulty in managing budgets. There is a need for a simple tool that allows users to record expenses, categorize them, and view their spending pattern without requiring complex software or databases. This project aims to provide a straightforward command-line solution for storing, viewing, and analyzing personal expenses.

Scope of the Project
>The project covers the basic functionalities required for personal expense tracking. It allows users to add expenses, store them permanently in a text file, view all records, search expenses by category, and generate a summary report showing total spending and category-wise distribution. The project focuses on simplicity and usability, using only Python and text-based data storage. Advanced features like editing, deleting, charts, or multi-user support are not included in this version.

Target Users
>The application is designed for individuals who want an easy and lightweight way to track daily expenses. It is suitable for students, working professionals, or anyone who wants a simple tool without installing heavy applications or using spreadsheets. It is also useful for beginners learning file handling and data management in Python.

High-Level Features
>Add new expense entries with amount, category, and description
>View all recorded expenses in a clean list format
>Search expenses based on categories
>Generate a summary report including total, highest, lowest, and category-wise spending
>Automatic loading and saving of all data in a text file
>Simple command-line interface that runs on any computer with Python installed
